## Selected work

A full stack system that a drone repair business in Poland uses to manage its repairs, live at [repair.drone-partss.com](https://repair.drone-partss.com). A WhatsApp booking assistant for clinics, in active development. A TypeScript, Express and LangChain backend answers questions about services and books appointments in PostgreSQL. It has a React dashboard, runs in Docker Compose, and is tested with Vitest and Playwright in GitHub Actions. The repository is private.
